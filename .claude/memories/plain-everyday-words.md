# Plain everyday words

The script of every production must be in plain language that a person with no technical background understands, word by word. It must not come across as technical. The user said this on 2026-11-14 after reading script draft 3 of the Gödel machines film, and pointed at one word as an example of vocabulary a general viewer does not have: "docile", which draft 3 carried over from I. J. Good's 1965 sentence. On 2026-11-15 the user decided that the rule holds for every production (see [The repo is a media factory](the-repo-is-a-media-factory.md)).

**Why:** The audience of the Gödel machines film is the general public (see [Video production decisions](video-production-decisions.md)). Claude's interpretation: a single unfamiliar word makes a viewer stop following, so a hard word is a fault even inside a quotation.

**How to apply:** Choose the everyday word every time ("test" over "benchmark", "the number" over "utility", "proved" over "theorem", "obedient" over the word in the example). When a source uses a hard word, restate the source in everyday words and do not quote it. The script carries no source notes (see [Script holds only narration](script-holds-only-narration.md)). Keep a technical term only when the story cannot do without it (in the Gödel machines film: recursive, language model, coding agent, archive, clade, objective hacking), and explain it in everyday words where it first appears. The same goes for text on screen. Check each draft by listing the words that are rare in everyday speech and replacing or justifying each one; on 2026-11-14 Claude did this with a public word-frequency list built from film subtitles and a small script in the session scratchpad, which is not kept in the repo. This sits alongside [No analogies in script](no-analogies-in-script.md): plain words, real mechanisms, no comparisons.
