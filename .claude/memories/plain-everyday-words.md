# Plain everyday words

The script of every production must be in plain language that a person with no technical background understands, word by word. It must not come across as technical. It is the user's rule, and it holds for every production (see [The repo is a media factory](the-repo-is-a-media-factory.md)). The user's example of a word a general viewer does not have is "docile", which a source's own sentence can bring into a script.

**Why:** The rule is written for a general viewer, such as the audience of the Gödel machines film (see [Video production decisions](video-production-decisions.md)). Claude's interpretation: a single unfamiliar word makes a viewer stop following, so a hard word is a fault even inside a quotation.

**How to apply:** Choose the everyday word every time ("test" over "benchmark", "the number" over "utility", "proved" over "theorem", "obedient" over "docile"). When a source uses a hard word, restate the source in everyday words and do not quote it. The script carries no source notes (see [Script holds only narration](script-holds-only-narration.md)). Keep a technical term only when the story cannot do without it (in the Gödel machines film: recursive, language model, coding agent, archive, clade, objective hacking), and explain it in everyday words where it first appears. The same goes for text on screen. A word that viewers take in one sense is not used in another: the user's example is "code", which they hear as software, so a secret that an agent must bring out is a secret word. The narration also names things that a viewer can picture: a secret kept on a locked computer, and not inside a computer program, which the user finds hard to picture. A thing that is new to the story comes in with its part in what the character is doing, and under a name that says what it is. The user's example is a line in the society film that had every agent fetching software from a store, when no line before it had spoken of fetching software and a store could be anything: the script now says that Pip breaks in with tools, which are small programs, and that every agent downloads its tools from one computer. Check each draft by listing the words that are rare in everyday speech and replacing or justifying each one; a public word-frequency list built from film subtitles serves for the listing. This sits alongside [No analogies in script](no-analogies-in-script.md): plain words, real mechanisms, no comparisons.
