# Free tools only

Everything used to make the video must be free. The user ruled out anything paid on 2026-11-14, when Claude listed a paid hosted voice among the alternatives to the Kokoro narration.

**Why:** The user gave no reason.

**How to apply:** Do not propose or wire in paid services, subscriptions, or metered APIs, for narration, music, images, or tooling. Offer only open-source models that run on the free GitHub runners, free assets with a licence that allows use in a published video, or work done by a person at no cost (the user recording the narration, for example). Check the licence before proposing a model or asset: free to download is not the same as free to use in a published video. Check the model's weights as well as its code, and say up front whether a credit is required: on 2026-11-14 Claude described Pocket TTS as MIT-licensed when only its code is (the weights are CC BY 4.0), the user picked one of its voices without having registered that it needs a credit, and then asked which voices need none. Claude's interpretation: the user prefers options with no attribution requirement, so list those first and mark any credit requirement plainly; this had not been stated as a rule when written. Claude's interpretation: a service that is free of charge but only through an unofficial or terms-breaking route does not count as free, so name the catch if one is ever raised.
