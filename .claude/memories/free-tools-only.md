Everything used to make the video must be free. The user ruled out anything paid on 2026-11-14, when Claude listed a paid hosted voice among the alternatives to the Kokoro narration.

**Why:** The user gave no reason.

**How to apply:** Do not propose or wire in paid services, subscriptions, or metered APIs, for narration, music, images, or tooling. Offer only open-source models that run on the free GitHub runners, free assets with a licence that allows use in a published video, or work done by a person at no cost (the user recording the narration, for example). Check the licence before proposing a model or asset: free to download is not the same as free to use in a published video. Claude's interpretation: a service that is free of charge but only through an unofficial or terms-breaking route does not count as free, so name the catch if one is ever raised. Related: [Video production decisions](video-production-decisions.md).
