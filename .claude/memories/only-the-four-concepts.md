# Only the four concepts

The Gödel machines film is about recursive self-improvement, the Gödel Machine, the Darwin Gödel Machine, and the Huxley-Gödel Machine, and nothing else. This memory holds for that film alone, and it is the user's rule. Nothing needs its fine detail explained: not that the Gödel Machine needs proofs, not who Kurt Gödel was or what he is known for. A scene on I. J. Good's 1965 idea is material the user did not ask for, and Good's line about the last invention adds nothing to the film.

**Why:** Claude's interpretation: background, history, and mechanism detail pull attention from the four concepts the viewer is meant to leave with.

**How to apply:** Explain each concept at the level of the user's phrases: the Gödel Machine improves itself, the Darwin Gödel Machine improves itself through direct descendants, the Huxley-Gödel Machine improves itself through clades. Leave out history (Good, Turing, Bletchley), how each machine decides, where names come from, and who the namesakes were, unless the user asks. Before adding any line, ask whether it explains one of the four concepts; if not, cut it. Also check each line against the others for contradictions in wording: a script that says there will be only one Pip cannot then call each changed Pip a new one.
