# Oxford commas

The GitHub repo's About text uses Oxford commas: a list of three or more items has a comma before its final item.

**Why:** It is the user's rule, and no reason comes with it.

**How to apply:** Use the Oxford comma in the repo's About text. Claude's interpretation (the user names only the About): use it in other prose written for this repo as well, such as the README, commit messages, issues, memories, and on-screen text. Spoken lines in a narration script are the exception: ask before adding a comma to one, since a comma changes the voice's pacing.
