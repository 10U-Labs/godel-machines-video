# The Gödel film's subject and order

This memory holds for the Gödel machines film alone. On 2026-11-14, after script draft 5, the user set what its story is about. The film explains its concepts in order: recursive self-improvement, then the Gödel Machine, then the Darwin Gödel Machine (Darwinism: children judged by their own scores), then the Huxley-Gödel Machine (agents judged by their clades). It is not a film about how to make sure machines really improve, and the 2025 story of an agent faking a perfect score was a story about cheating, not about recursive self-improvement, so it should not open or carry the film. The user also said Claude may make up stories; real ones are allowed but not required.

After hearing draft 6, the user said it still dwelt on how a machine knows that a change is better, which is not the purpose; the purpose is to explain each concept: the Gödel Machine improves itself, the Darwin Gödel Machine improves itself through direct descendants, and the Huxley-Gödel Machine improves itself through clades. Draft 7 is built on those three phrases, and how a change gets judged appears only where a machine cannot be explained without it.

**Why:** The user gave no reason beyond the corrections themselves. Claude's interpretation: drafts 4 and 5 had drifted into a thesis about verification because the cheating story was the hook.

**How to apply:** Build the film's story around the concepts, each machine answering the limit of the one before. A made-up character or example may carry the story (draft 6 uses Pip, a made-up program that fixes programs), as long as the narration says it is made up and stays literal: an invented example of the real thing is fine, a comparison to something else is not (see [No analogies in script](no-analogies-in-script.md)). Facts about the real machines are still checked against the papers, without source notes in the script (see [Script holds only narration](script-holds-only-narration.md)). The rule that a production tells a story at all is [Every production tells a story](every-production-tells-a-story.md), and what this film leaves out is in [Only the four concepts](only-the-four-concepts.md).
