# The Gödel film's subject and order

This memory holds for the Gödel machines film alone, and what it sets is the user's direction. The film explains its concepts in order: recursive self-improvement, then the Gödel Machine, then the Darwin Gödel Machine (Darwinism: children judged by their own scores), then the Huxley-Gödel Machine (agents judged by their clades).

The purpose is to explain each concept: the Gödel Machine improves itself, the Darwin Gödel Machine improves itself through direct descendants, and the Huxley-Gödel Machine improves itself through clades. It is not a film about how to make sure machines really improve, or about how a machine knows that a change is better; how a change gets judged appears only where a machine cannot be explained without it. The 2025 story of an agent faking a perfect score is a story about cheating, not about recursive self-improvement, so it does not open or carry the film. Claude may make up stories; real ones are allowed but not required.

**Why:** No reason comes with the direction. Claude's interpretation: a script that takes the cheating story as its hook drifts into a thesis about verification, and one that dwells on how changes are judged loses the concepts.

**How to apply:** Build the film's story around the concepts, each machine answering the limit of the one before. A made-up character or example may carry the story (the script uses Pip, a made-up program that fixes programs), as long as the narration says it is made up and stays literal: an invented example of the real thing is fine, a comparison to something else is not (see [No analogies in script](no-analogies-in-script.md)). Facts about the real machines are still checked against the papers, without source notes in the script (see [Script holds only narration](script-holds-only-narration.md)). The rule that a production tells a story at all is [Every production tells a story](every-production-tells-a-story.md), and what this film leaves out is in [Only the four concepts](only-the-four-concepts.md).
