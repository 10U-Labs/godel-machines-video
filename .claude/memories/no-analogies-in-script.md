# No analogies in script

The script of every production made in this repo must not use analogies. The user set the rule on 2026-11-14 for the Gödel machines film, together with that film's audience (the general public), after Claude had proposed carrying the ideas by analogy for a general audience. On 2026-11-15 the user decided that the rule holds for every production (see [The repo is a media factory](the-repo-is-a-media-factory.md)).

**Why:** The user gave no reason. Claude's interpretation: they want the real mechanism of a subject explained in plain language, not replaced by a comparison to something else.

**How to apply:** In the narration script and on-screen text of any production, describe what the subject actually does and define terms plainly. For the Gödel machines film, whose audience is the general public, assume no maths or programming background. Do not write comparisons or metaphors that stand in for the mechanism. The pictures are different: on 2026-11-14, when asked whether the visuals could use metaphor the way Kurzgesagt's do, the user said yes. So the narration stays literal, and the pictures may draw ideas as objects, creatures, or places, as long as they do not contradict the real mechanism the voice describes. Related: [Video production decisions](video-production-decisions.md).
