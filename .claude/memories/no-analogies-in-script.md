The video is for the general public, and its script must not use analogies. The user set both together when asked who the video is for (2026-11-14), after Claude had proposed carrying the ideas by analogy for a general audience.

**Why:** The user gave no reason. Claude's interpretation: they want the real mechanism of each machine explained in plain language, not replaced by a comparison to something else.

**How to apply:** In the narration script and on-screen text for this video, describe what each machine actually does, define terms plainly, and assume no maths or programming background. Do not write comparisons or metaphors that stand in for the mechanism. Visuals should depict the actual process (code, proofs, agents, benchmarks), not a metaphorical stand-in. Scope: this video; ask before assuming it applies to other projects. Related: [Video production decisions](video-production-decisions.md).
