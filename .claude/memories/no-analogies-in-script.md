# No analogies in script

The video is for the general public, and its script must not use analogies. The user set both together when asked who the video is for (2026-11-14), after Claude had proposed carrying the ideas by analogy for a general audience.

**Why:** The user gave no reason. Claude's interpretation: they want the real mechanism of each machine explained in plain language, not replaced by a comparison to something else.

**How to apply:** In the narration script and on-screen text for this video, describe what each machine actually does, define terms plainly, and assume no maths or programming background. Do not write comparisons or metaphors that stand in for the mechanism. The pictures are different: on 2026-11-14, when asked whether the visuals could use metaphor the way Kurzgesagt's do, the user said yes. So the narration stays literal, and the pictures may draw ideas as objects, creatures, or places, as long as they do not contradict the real mechanism the voice describes. Scope: this video; ask before assuming it applies to other projects. Related: [Video production decisions](video-production-decisions.md).
