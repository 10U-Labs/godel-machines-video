# The film tells a story

The video has to tell a story, hook the audience, and have what the user calls soul. On 2026-11-14 the user watched the first rendered scene, which followed script draft 2 (accurate, in textbook order, with no people or stakes in it), and judged it only passable for this reason.

**Why:** The user gave no further reason. Claude's interpretation: a correct explanation does not hold a general audience by itself; viewers need a question to care about, people, tension, and a payoff.

**How to apply:** Open on a concrete, true moment that raises a question. Carry real people and one through-line question across the film, let each machine answer the failure of the one before, and return to the opening at the end. The story comes from real events and real mechanisms, never from comparisons, so [No analogies in script](no-analogies-in-script.md) still holds, and Claude still checks every fact against a primary source (without writing source notes into the script; see [Script holds only narration](script-holds-only-narration.md)). The hook comes from the facts, not from words that hype them; see [State facts plainly](state-facts-plainly.md). Apply the same test to picture, music, and voice, not only to the words.

On 2026-11-14 the user also asked Claude to check whether the rule that Trey Parker and Matt Stone use for story outlines helps here: between any two beats the joining word should be "but" or "therefore", and never "and then". Claude judged that it does and applied it in script draft 4: every scene now follows from the one before as a consequence or a setback, the joins are written out at the top of `script/script.md`, and the scene on the perfect score moved to just before the ending because of it. Keep testing new or reordered scenes this way; a scene that can only be joined with "and then" is a list item and should be cut, merged, or given a cause. The user began reading draft 4 later that day and gave notes on its opening, which led to draft 5. The wording rule that came with it is [Plain everyday words](plain-everyday-words.md).
