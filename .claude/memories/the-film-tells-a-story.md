# The film tells a story

The video has to tell a story, hook the audience, and have what the user calls soul. On 2026-11-14 the user watched the first rendered scene, which followed script draft 2 (accurate, in textbook order, with no people or stakes in it), and judged it only passable for this reason.

Later that day, after script draft 5, the user set what the story is about. The film explains three concepts in order: recursive self-improvement, then the Gödel Machine, then the Darwin Gödel Machine (Darwinism: children judged by their own scores), then the Huxley-Gödel Machine (agents judged by their clades). It is not a film about how to make sure machines really improve, and the 2025 story of an agent faking a perfect score was a story about cheating, not about recursive self-improvement, so it should not open or carry the film. The user also said Claude may make up stories; real ones are allowed but not required. After hearing draft 6, the user said it still dwelt on how a machine knows that a change is better, which is not the purpose; the purpose is to explain each concept: the Gödel Machine improves itself, the Darwin Gödel Machine improves itself through direct descendants, and the Huxley-Gödel Machine improves itself through clades. Draft 7 is built on those three phrases, and how a change gets judged appears only where a machine cannot be explained without it.

**Why:** The user gave no further reason for the hook. Claude's interpretation: a correct explanation does not hold a general audience by itself; viewers need someone to follow, a question, and a payoff. Drafts 4 and 5 had drifted into a thesis about verification because the cheating story was the hook.

**How to apply:** Build the story around the three concepts, each machine answering the limit of the one before. A made-up character or example may carry the story (draft 6 uses Pip, a made-up program that fixes programs), as long as the narration says it is made up and stays literal: an invented example of the real thing is fine, a comparison to something else is not (see [No analogies in script](no-analogies-in-script.md)). Facts about the real machines are still checked against the papers, without source notes in the script (see [Script holds only narration](script-holds-only-narration.md)). The hook comes from the story, not from hype words; see [State facts plainly](state-facts-plainly.md). Keep each scene to one idea; see [One idea at a time](one-idea-at-a-time.md). Apply the same test to picture, music, and voice.

On 2026-11-14 the user also asked Claude to check whether the rule that Trey Parker and Matt Stone use for story outlines helps here: between any two beats the joining word should be "but" or "therefore", and never "and then". Claude judged that it does, and the joins are written out at the top of `script/script.md`. Keep testing new or reordered scenes this way; a scene that can only be joined with "and then" should be cut, merged, or given a cause. The wording rule is [Plain everyday words](plain-everyday-words.md).
