# Every production tells a story

A production has to tell a story, hook the audience, and have what the user calls soul. On 2026-11-14 the user watched the first rendered scene of the Gödel machines film, which followed script draft 2 (accurate, in textbook order, with no people or stakes in it), and judged it only passable for this reason. On 2026-11-15 the user decided that the rule holds for every production (see [The repo is a media factory](the-repo-is-a-media-factory.md)).

On 2026-11-14 the user also asked Claude to check whether the rule that Trey Parker and Matt Stone use for story outlines helps here: between any two beats the joining word should be "but" or "therefore", and never "and then". Claude judged that it does. Test new or reordered scenes this way; a scene that can only be joined with "and then" should be cut, merged, or given a cause. In the Gödel machines film the joins are written out at the top of `script/script.md`.

**Why:** The user gave no further reason for the hook. Claude's interpretation: a correct explanation does not hold a general audience by itself; viewers need someone to follow, a question, and a payoff.

**How to apply:** Give the viewer someone to follow, a question, and a payoff, and apply the same test to picture, music, and voice. The hook comes from the story, not from hype words; see [State facts plainly](state-facts-plainly.md). Keep each scene to one idea; see [One idea at a time](one-idea-at-a-time.md). The wording rule is [Plain everyday words](plain-everyday-words.md), and the story stays literal; see [No analogies in script](no-analogies-in-script.md). What a production's story is about is settled for each production; for the Gödel machines film it is in [The Gödel film's subject and order](godel-film-subject-and-order.md). For that film the user allowed made-up stories and characters. Claude's interpretation, not confirmed: the same holds for other productions, as long as the narration says what is made up.
