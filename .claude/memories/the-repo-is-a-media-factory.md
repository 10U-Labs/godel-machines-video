# The repo is a media factory

On 2026-11-15 the user stated that this repository is now a factory for media, and no longer a factory for one video. By then it had been renamed from `godel-machines-video` to `media-factory`. The Gödel machines film, first rendered in full on 2026-11-14, is its first production.

**Why:** The user gave no reason.

**How to apply:** Treat the Gödel machines film as one production among those to come. Put nothing that belongs to a single production (its script, scenes, characters, names, voice, or music) into shared code under `src/`, into a workflow, or into a rule meant for the whole repository. Issues 1 to 9 on GitHub, filed that day at the user's request, lay out the conversion; read them before restructuring anything.

The memories written on 2026-11-14, while the repo made one film, were sorted on 2026-11-15 (issue 9). `MEMORY.md` lists them under two headings, one for the factory and one for the Gödel machines film.

- Decided by the user on 2026-11-15: the seven rules about writing and pictures, each first given as a correction to a draft of the Gödel machines film, hold for every production. They are [No analogies in script](no-analogies-in-script.md), [Plain everyday words](plain-everyday-words.md), [State facts plainly](state-facts-plainly.md), [Script holds only narration](script-holds-only-narration.md), [Show people, not panels](show-people-not-panels.md), [One idea at a time](one-idea-at-a-time.md), and [Every production tells a story](every-production-tells-a-story.md). Apply them to a new production without asking again.
- Claude's sorting, shown to the user on 2026-11-15 and not objected to, but not a stated decision: the rules about how work is done (rendering in workflows, free tools, and the others under the factory heading) hold for all work in the repo, and [Video production decisions](video-production-decisions.md), [Only the four concepts](only-the-four-concepts.md), and [The Gödel film's subject and order](godel-film-subject-and-order.md) belong to the Gödel machines film alone.

The look, voice, music, length, and audience of a new production are not settled by the Gödel machines film's choices, so ask. The plain-words rule is written for a general viewer; if a production is for a different audience, ask how the rule reads for it.

Claude's interpretation, not confirmed: a production is a narrated, animated video like the first one; the user's word was media, so other kinds may follow.
