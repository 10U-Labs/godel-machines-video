# The repo is a media factory

On 2026-11-15 the user stated that this repository is now a factory for media, and no longer a factory for one video. By then it had been renamed from `godel-machines-video` to `media-factory`. The Gödel machines film, first rendered in full on 2026-11-14, is its first production.

**Why:** The user gave no reason.

**How to apply:** Treat the Gödel machines film as one production among those to come. Put nothing that belongs to a single production (its script, scenes, characters, names, voice, or music) into shared code under `src/`, into a workflow, or into a rule meant for the whole repository. Issues 1 to 9 on GitHub, filed that day at the user's request, lay out the conversion; read them before restructuring anything. The memories written on 2026-11-14 speak of the film or the video. Which of their writing and picture rules hold for every production is the user's decision and is open in issue 9, so ask before applying them to a new production. Claude's interpretation, not confirmed: a production is a narrated, animated video like the first one; the user's word was media, so other kinds may follow. Related: [Video production decisions](video-production-decisions.md).
