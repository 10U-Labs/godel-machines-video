# Is Ultron a Gödel Machine?

Narration script, draft 3. One paragraph is one voiced line. Lines starting
with ">" are notes and are not voiced.

The film takes Ultron, the artificial intelligence in the 2015 film Avengers:
Age of Ultron, and asks whether he is what computer science calls a Gödel
Machine. Of that film's plot it tells three steps: Ultron starts as a program
with no body, he makes himself a feeble body, and then he makes himself a
powerful one. Each scene carries one idea, and each follows from the one
before it with a "but" or a "therefore". The joins:

> 00 Ultron starts up as a program with no body. He wants one, BUT nobody is there to build it, THEREFORE he builds it himself.
> 01 He has no hands, BUT the lab's machines are run by computers, THEREFORE he has them build him a body. BUT their parts come from broken robots, THEREFORE the body is feeble.
> 02 THEREFORE the heroes smash it. BUT they have only smashed a body: Ultron is a program, THEREFORE he leaves over the internet.
> 03 THEREFORE he needs a new body, and builds a stronger one in a lab made for building robots.
> 04 THEREFORE he is a machine that makes itself better, and computer science has a design for one: is he a Gödel Machine?
> 05 THEREFORE what a Gödel Machine is: a program is text, THEREFORE it can rewrite its own code.
> 06 THEREFORE the two can be compared, and one thing matches: each improves itself, and no person makes the changes.
> 07 BUT what changes is not the same: Ultron's body, and the Gödel Machine's code.
> 08 THEREFORE only the Gödel Machine gets better at getting better.
> 09 BUT a change can also make the code worse. THEREFORE a Gödel Machine changes nothing without proof, and Ultron proves nothing.
> 10 THEREFORE the answer is no.
> 11 BUT a real program now rewrites its own code, and it has no body, as Ultron had none when he started.

## 00-no-body | A program with no body

A computer program starts up, alone, in a lab. It can think, and it can talk. But it has no body.

One of the first things it asks about is a body.

This is Ultron, from the 2015 film Avengers: Age of Ultron.

In the film, two of the heroes, Tony Stark and Bruce Banner, try to make a program that will protect the world.

But they cannot get it to start, so they leave for a party. While they are gone, it starts by itself.

[pause 0.8]

Ultron wants a body. But there is nobody in the lab to build one for him. So he builds it himself.

## 01-a-feeble-body | A feeble body

Ultron has no hands. But the machines in the lab are run by computers, and he is a program. So he takes control of them.

The machines build him a body. But the parts they have come from broken robots, so the body is feeble.

Ultron moves into it, and walks it out of the lab.

## 02-only-a-body | Only a body

He walks it into the party, to fight the heroes. But the body is feeble, and they smash it.

But they have only smashed a body. Ultron is a program, and a program can be sent from one computer to another.

He has already left, over the internet.

## 03-a-powerful-body | A powerful body

Now Ultron needs a new body. So he goes to another lab, and this one is full of machines for building robots.

With them, he builds himself a body that is bigger than the first, and much stronger.

## 04-the-question | The question

So Ultron has had three forms. A program with no body. Then a feeble robot. Then a powerful one.

And every one of those changes was made by Ultron himself.

So Ultron is a machine that makes itself better. Computer science has a design for a machine that does that. It is called the Gödel Machine.

So here is the question. Is Ultron a Gödel Machine?

## 05-the-godel-machine | The Gödel Machine

To answer that, start with what a Gödel Machine is.

In 2003, a computer scientist named Jürgen Schmidhuber described it.

A Gödel Machine is a computer program. And a program is a piece of text: a list of instructions, called its code.

Text can be rewritten. So while a Gödel Machine does its job, it rewrites its own code, so that it does the job better.

It can rewrite any part of that code. Even the part that does the rewriting.

## 06-what-matches | What matches

Now Ultron can be compared with it. Start with what matches.

A Gödel Machine improves itself. No person makes the changes.

Ultron is the same. No person builds his bodies. He does.

## 07-what-changes | What changes

But what changes is not the same.

In Ultron, it is the body. The film never shows his program being rewritten. The same program moves into a better body.

In a Gödel Machine, it is the code: the instructions that decide everything the machine does.

So Ultron ends up with a better body. A Gödel Machine ends up with better code.

## 08-better-at-getting-better | Better at getting better

A Gödel Machine's code does many things, and one of them is rewriting the code. So when the code gets better, the rewriting gets better too.

Then the next change can be a better one. And the one after that, better still.

A stronger body does not do that. It makes Ultron harder to smash. It does not make him better at improving himself.

## 09-proof-first | Proof first

But a change can also make the code worse. And then every later change is made by worse code.

So a Gödel Machine does not change its code on a guess. First it has to prove, with mathematics, that the change will make it do better. Until it has that proof, it changes nothing.

The film shows no step like that. Ultron builds a body, and walks out in it.

## 10-the-answer | The answer

So, is Ultron a Gödel Machine? No.

He does improve himself, and no person helps him. But what he improves is his body, not his code. And nothing in the film shows him proving that a change is for the better.

## 11-a-real-program | A real program

The Gödel Machine itself has never been built.

But in 2025, researchers built a program that fixes other programs, and had it rewrite its own code, again and again.

Its first version fixed 20 problems in a hundred. After 80 rounds, its best version fixed 50.

That program has no body. All that got better is its code.

It is what Ultron was when he started up: a program, with no body.

The next thing Ultron did was build a body. The next thing it does is rewrite itself.
